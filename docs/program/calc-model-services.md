# Calc document model service prerequisites

`ScModelObj` implements the original three `XServiceInfo` methods and queries that actual interface before its existing base-model fallback. Service identity remains independent of shell initialization, including options-only and Dying states. The implementation name is `ScModelObj`, and the original three supported document service names retain their order and exact case. The shared `cppu::supportsService` implementation supplies membership.

`ScServiceProvider` represents all 51 original enum ordinals, 60 modern catalog rows, ten old compatibility rows, exact modern-first lookup and the original ordered UNO sequence return. Nine symbolic service names retain their original `unonames.hxx` boundary. The header exports the provider class as a type declaration; executable consumers import its source implementation, avoiding a header/implementation initialization cycle in ESM. Compiler-erased sequence element addresses use byte offsets and actual RTL pointer cells. Native container/allocator/thread/ABI domains remain unqualified.

The witness compiles the unchanged original enum, tables and `GetProviderType` body with Clang/UBSan; only native string spelling changes to `std::u16string_view`, `_ustr` is erased and the original debug-only `OSL_FAIL` is disabled as in a release build. It records catalog order and provider results. It does not replace the production lookup. Original `apitest::XServiceInfo` assertions are ported against real model/reference owners; the whole original ODS-loaded suite is not claimed executed. CALC688 preserves the original duplicate VBA globals row.

The Chromium probe queries service information on the real model referring to the document filled by `ScDocumentImport`, in main and DOM-free Worker realms. This does not provide the missing complete `XModel`, `ScServiceProvider::MakeInstance`, `XMultiServiceFactory`, formatter aggregation, full model type list, document filter/storage orchestration or mounted DOCX/XLSX file UI. Those paths remain required before whole-format acceptance.
