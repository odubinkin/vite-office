# DOCX and XLSX file filters

The existing Writer file dialog opens DOCX through the shell, WriterFilter, OOXMLDocument and DomainMapper. The import creates a separate Writer graph, applies the represented named styles and numbering definitions before the body, and installs the graph only if the open request still matches the active document. The download command exports the active graph through DocxExport, the native run serializer and the existing OOXML package transport. The named-style part preserves represented paragraph and character properties, base styles and paragraph follow styles. Body paragraphs and runs reference these definitions through the shared Word style IDs. The primary ODT path preserves Western, Asian and complex language attributes from imported styles. The primary ODT path preserves common character style identity, parent styles and direct formatting, including a DOCX export after reopening the saved browser copy. Writer shares the native Word numbering traversal with RTF and writes DOCX list definitions, paragraph references and scoped restart overrides. The primary ODT copy preserves Latin, Roman and repeated-letter list formats.

The Calc file dialog sends XLSX to ExcelFilter and its workbook and worksheet fragments. The filter creates all worksheet owners before loading cells. It resolves shared strings through workbook relationships and builds scalar and shared formulas through the Calc compiler and cell owners. The styles fragment resolves font, literal solid fill and alignment records into native cell patterns. It stores the XLSX Normal XF as the native Calc Default cell style. Primary ODS and its Worker transfer preserve that named style and the separate document-wide pool defaults. The worksheet uses native row and column dimensions, including hidden and manually sized rows. The package generator controls Excel's 0.75-point row rounding, and the browser connects its VCL measurements of the workbook's default font to worksheet column widths. The download command serializes sparse values, formulas, styled blanks, column defaults, dimensions and compiled number formats through XclExpXmlStream. The grid uses ScCellFormat for numeric display. Primary ODS storage uses native ODF data styles for the represented numeric cases, including percentages, dates, scientific notation and positioned literals.

The browser stores opened documents through the same ODT and ODS primary storage paths. Downloads use the existing export ports. They preserve the active medium, modification status and primary-save state.

Writer round-trips the represented run and paragraph properties, links and bookmarks, line numbering, page descriptors and header and footer content, including supported embedded images. WordprocessingML table events convert native text ranges into Writer table nodes. The table path preserves nested tables, grids, column spans, vertical merges, cell alignment, row height and split settings, and supported direct and conditional cell fills. Floating tables, other drawing types and additional Word properties depend on corresponding Writer owners.

Calc imports worksheet merge ranges and writes them from native merge attributes, including empty anchors. Primary ODS preserves these ranges through ODF span and covered-cell elements. The XLSX paths also preserve formatted text runs, represented theme references, frozen panes, print ranges and implemented conditional rules, including color scales. Data bars and icon sets depend on corresponding Calc owners. Formula import and export use the grammar and functions implemented by the Calc core.

The file filters use the shared OOXML package and SAX paths. Their file controls are shared with the primary ODT and ODS paths and retain the browser's existing storage and save behavior.

Calc preserves nested row and column outlines and hidden geometry through XLSX and primary ODS, including the Worker transport. The pinned LibreOffice outline fixture checks the four-level geometry and XLSX collapse markers.

Calc preserves inline named arrays and evaluates them as arguments to SUM, SUMSQ, PRODUCT and AVERAGE. The pinned named-range workbook exercises the imported matrix through the Worker, primary ODS and XLSX export and reopen.

Writer initializes DOCX without run defaults to Calibri 11 pt. An explicit run-default section starts with Times New Roman 10 pt before applying its properties. The Worker preserves the script font sizes from the document pool, DOCX writes the represented Western and complex-script sizes, and ODT preserves the effective font sizes. Parentless Word styles still need the distinct Writer paragraph-root owner so they can inherit document defaults independently of Normal.
