# Native property map

SwXTextDefaults and the original property-set owners require SfxItemPropertyMap. This block supplies its original schema-value/index mechanism, rather than treating the older array-based property-info projection as an actual native map/component. It is a prerequisite within the still active DOCX/XLSX task, not a complete document-default application path.

SfxItemPropertyMapEntry owns real counted OUString and uno::Type members and retains native WhichId/flag/member/additional-flag widths. Constructor assertions preserve the flags ceiling, forbidden member bit and the five integer types accepted for METRIC_ITEM. Copy/assignment retain independent member ownership and source field order; destruction releases Type before the name. PropertyMoreFlags retains its original unsigned8 enum values. Unconsumed implicit move families and full compiled field/ABI behavior are not certified.

SfxItemPropertyMap uses the existing o3tl sorted_vector with the original stateless name comparator and actual OUString comparison. It stores borrowed entry pointers, keeps the first same-name insertion and performs source lower_bound lookup over exact counted UTF16 views, including embedded nulls and supplementary characters. The caller keeps its schema table alive and unchanged. The source pointer-vector copy is bound by inserting the same already ordered borrowed references; no schema entries are cloned. Mutation that would invalidate sorted schema invariants is not advertised as a supported source domain.

The map owns a lazily initialized real Sequence<Property>. Descriptor construction/assignment uses the genuine generated Property, UNO type/data assignment and existing sequence ownership machinery. The map returns a const sequence reference; a caller copies it to retain an owner. Copies made after cache initialization share the sequence handle, while copies made before initialization retain their own lazy cache slot. Real Sequence.getArray triggers COW; changing the caller's sequence leaves both map caches unchanged. getPropertyByName returns an independently owned Property and preserves UnknownPropertyException with the requested counted name and empty default context. Map destruction releases only its cached sequence, never the caller-owned entry table.

The older SfxItemPropertySetInfo array projection is still present and has not been relabeled as XPropertySetInfo or registered through a partial query provider. Its migration requires actual static map/provider ownership, full SfxItemPropertySet and real property-info component wiring. Those remain pending along with SwXTextDefaults, document/view/style application, complete DOCX/XLSX filters/export and mounted UI/Worker acceptance. Existing Open/Save/autosave/recovery policies are unchanged. Full module/default/service/ABI/native QA parity remains unverified.
