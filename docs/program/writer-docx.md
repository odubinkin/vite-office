# Writer DOCX pipeline

## Status

Implementation is in progress under task `202610251549-V4DQJW`, following the
user-approved shared OOXML → Writer DOCX → Calc XLSX plan. DOCX is not yet
advertised in the application's Open or download controls. Primary browser
storage remains ODT; recovery and autosave product decisions are unchanged.

## Source ownership

The pinned reference is LibreOffice `9bc445578031fecf56086729d8e4940c77e14d65`.
`WriterFilter` owns filter entry and dispatch. Import follows
`OOXMLStreamImpl`/`OOXMLDocumentImpl` into `DomainMapper`, which consumes the
existing `SwXTextDocument`, text, paragraph, style and table interfaces. Export
belongs to `DocxExportFilter`, `DocxExport` and `DocxAttributeOutput` over the
canonical Writer graph. DOCX is not converted to an intermediate ODT document.

The shared prerequisite `R2DJ64` supplies actual ZIP/SAX fragments,
relationships, type metadata and native URI handling. Its implementation commit
is `06a4c723d3b6699f098769caa31df70c99bf4e4b`.

## Implemented import resources

- Native numeric resource IDs are generated by the unchanged upstream
  `ooxml/resourceids.py` from `model.xml`. The consumed subset retains original
  numbers; omitted declarations do not renumber it.
- `OOXMLValue` retains the represented boolean, signed integer, universal
  measure, measure-or-percent, hexadecimal, string and property-set variants.
  Only boolean, integer and string variants produce a non-void `Any` in this
  consumed slice, exactly as the original method does.
- Original ON/OFF spellings, native RTL prefix and unsigned conversion,
  color/hash admission, half-point/twip/EMU scales, negative half rounding away
  from zero and percent truncation are preserved.
- `OOXMLPropertySet` preserves property order, duplicate IDs, reference sharing
  on clone, attribute/modifier channels and additions during resolution.
  `OOXMLTable` retains positions of admitted values without nested properties.
- `PropertyMap` uses actual typed `Any`, `PropertyValue` and `Sequence` owners,
  source numeric ordering, style-first output and four native interop bags.
  Overwrite/default and first-nonempty cache behavior remain source-exact.
- The current `DomainMapper` paragraph/run slice writes through actual
  `SwXText.appendTextPortion` and `finishParagraph`; it preserves three script
  families, native CR events and trailing-body-paragraph disposal. Lists,
  sections, tables, theme application and the remaining property handlers are
  still being implemented.
- Imported style lookup uses `StyleSheetTable` entry maps and typed DocDefaults,
  including three native 10pt heights and disabled auto-kerning. The full
  439-pair name map, reserved-name suffix and first duplicate ID are preserved.
  This owner does not yet parse/apply the complete stylesheet resource stream.
- `OOXMLStreamImpl` follows the Writer `XRelationshipAccess` sequence contract,
  exact strict/transitional types, external-ID cache, native custom-target and
  VBA nesting behavior. The consumed `stoc` generic URI owner preserves dot
  segments, escapes and excessive-parent policies through the native algorithm.
  This deliberately differs from the separate `oox::Relations` lookup contract.

Native binary/drawing/service variants are not advertised by this resource
slice. Native undefined floating-to-int casts and null attribute dereferences
are rejected explicitly at the host boundary; no wrap, saturation or successful
native result is claimed for those inputs.

## Remaining work and acceptance

Complete DomainMapper document/style/numbering/table/section mapping, canonical
DOCX export, shell filter routing, asynchronous cancellation/stale-generation
handling and existing Open/download UI integration. Acceptance requires
actual-model assertions for the current Writer feature slice, native fixture
imports, DOCX export/reopen, related ODT regressions and real production browser
Open/download/reopen scenarios. Resource tests alone do not prove DOCX document
or UI support. All parity attestations remain unverified until their own exact
contracts and evidence justify them.
