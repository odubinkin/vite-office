It does not seek, query, replace or open the retained input. The SfxDocumentMetaData load owner imports this actual namespace, removing its previously unresolved call. This is prerequisite plumbing; storage/service/model/filter and existing UI document roundtrips are still unfinished.

No positive URL/POST opening, authentication decision, interaction service or replacement provider is supplied by this checkpoint.

ReadOnly uses the original precedence: an explicit item returns its bool extraction result (false after failed extraction); PostData presence implies true; Stream presence implies false; an absent or wrongly typed UCBContent leaves false. The original file-scheme inference and RuntimeException rethrow versus other UNO exception handling are represented in source, but their positive/error paths remain unqualified. Existing file UCP code provides stream owners, not yet a registered file Content implementation. A positive test that assumed that missing service was removed rather than introducing a fake content/provider.
