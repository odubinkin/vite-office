This block supplies the missing storage SDK family required by the parent-bound OStorage/OWriteStream graph. All20 own methods retain original names, borrowed counted Unicode arguments, native signed32 modes, actual NamedValue sequences and owned interface-reference results. XStorage inherits XNameAccess and XComponent in original order. XStorage2 and hierarchical version2 keep their source parents. Hierarchical version1 has only the implicit XInterface root. Optional property/transaction capabilities are not silently made mandatory.

Normal cppumaker-style getters use actual UnoType/Type values and typelib_static_mi_interface_type_init. Tests verify source qualified names, cached type pointers, real base assignability and exclusion of optional bases. The normal binding is not a claim of full external type-library-driven member/exception reflection or compiled virtual-layout/ABI parity. No class implementing a partial storage service or query provider is constructed merely to exercise its declared interfaces.

InvalidStorageException uses its real IOException parent type. StorageWrappedTargetException uses WrappedTargetException, including its inherited owned TargetException Any. Constructors, copy/move, assignment and exactly-once destruction delegate to existing native value owners. Tests use real initialized primitive cells and actual Any/Reference/OUString values, not a host Error-shaped substitute. The initial fixture incorrectly passed a scalar rather than its native address to typed Any construction and attempted a runtime static API on the declaration-only XInterface surface; both were corrected to the genuine native mechanisms.

These are concrete prerequisites, not completed storage behavior. Existing flat ZipStorage is not relabeled as implementing XStorage, and no native parent/package/factory/context is forged. Complete OStorage/OWriteStream, package stream/service graph, serializer Reference output wiring, DOCX/XLSX document drivers and mounted Worker/UI acceptance remain unfinished. Declaring encrypted-stream signatures does not implement encryption. Browser Open/Save/autosave/recovery policies are unchanged. Related existing input/transaction/typelib/wrapped-value and format regressions validate the consumed owner graph; checkpoint evidence records exact commands, outcomes and source hashes.
