# Native package metadata entry output

ZipPackage now exposes its original WriteMimetypeMagicFile, WriteManifest and WriteContentTypes entry points. Their actual receiver, context, root folder and native sequences are retained. A responsibility split moves the entry writers into ZipPackage.serialization.ts; it does not introduce a second package tree or a replacement writer/provider. The existing flat transport/helper routes are unchanged until complete native package commit is available.

Mimetype output removes an existing root member, converts the actual root media type with the original ASCII encoding, writes a STORED entry and computes CRC through the real source owner. A real closed output produces the original WrappedTargetException message, actual package Context and typed IOException target. ZipEntry now distinguishes default aggregate construction from the compiler-known value-initialization used by std::make_unique<ZipEntry>(); only that selected form zeros scalar members. Existing unspecified default-initialized scalar values remain unspecified.

Manifest output queries the registered ManifestWriter, copies the actual vector of property sequences into the original sequence-of-sequences shape, serializes into ZipPackageBuffer and writes a DEFLATED entry through ZipOutputEntry. Content-type output retains the five source defaults, exact case-sensitive extension/type comparison, empty-type omission and original leading-slash construction. It uses the registered SAX Writer through OFOPXMLHelper::WriteContentSequence and the same native buffer/deflater/record path. No metadata entry is encrypted by these source functions.

Focused tests independently inflate compressed bytes and check CRC, methods and lengths with Node zlib, then reopen the actual archive through native input. XML parsing independently checks namespace/default/override/file-entry semantics. Chromium main and DOM-free Worker write and reopen all three native metadata entries together. The existing ManifestExport supports the ordinary unencrypted OASIS-root domain; empty or legacy manifest export still reaches an explicit missing prerequisite. No synthetic root or new positive acceptance is supplied for that domain. Original full StorageFactory/package QA remains pending complete commit/services.

Two earlier OStorage_Impl property extraction calls were also corrected to pass the real OUString owner required by the actual Any string overload, rather than its data-address cell. Actual positive PACKAGE property acquisition remains unqualified because the native package property service is not yet implemented; this correction does not claim that missing positive path was tested.

Whole serialization/ZipEntry coverage reaches the unchanged90 gate after including the existing stream-save tests that exercise the original record copy/assignment owner. The initial serialization-only test scope's ZipEntry coverage failure is retained. Prior full ZipPackage, background task, internal storage and MediaDescriptor coverage failures remain unfinished. Root writeTempFile/commit/transfer, large-stream scheduler/parallel deflate, OStorage/StorageFactory/SfxMedium, classic SAX parser, real DOCX/XLSX model/filter/UI roundtrips and native physical ABI/thread/allocation parity remain unfinished. The same three SfxMedium type errors and two existing dependency diagnostics persist. Existing browser open/save/autosave/no-recovery choices remain unchanged.

Original ConnectTo now performs the throwing seekable query, input assignment and seek-to-zero in source order. An existing ZipFile receives only setInputStream; a new reader is constructed with initialise=false and the original format-specific Checks. Its catalog is not re-enumerated. A genuine saved ZipPackageStream reads its payload after metadata output and rebinding; a later replacement preserves ZipFile identity. A real nonseekable wrapper exercises the original failed query. Main and Worker also verify same-reader identity and the deliberately empty new-reader catalog. Native debug ByteReader assertions remain unqualified.
